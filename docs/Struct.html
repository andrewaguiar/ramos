Struct — reading and replacing the attributes of a struct instance.

A struct declares its attributes once, with defaults, and an instance is built with the literal form: Person{name: "Andrew", age: 40}. The shape is fixed at definition time, so these functions never add or drop an attribute — naming one the struct does not declare is an error rather than a silent extra.

Instances are immutable like every other value: put returns a new instance and leaves the original alone.

andrew = Person{name: "Andrew", age: 40}
older =
  andrew
  | Struct.put(:age, 41)

Person is the struct the examples below are written against:

# ramos doctest setup
struct Person
  attributes
    name: nil
    age: 0

The field-assignment form is sugar for exactly that call, rebinding the name it reads from:

andrew.age = 41     # andrew = Struct.put(andrew, :age, 41)

Reading a field needs no function at all — andrew.name is the dot form, and get exists for the piped and defaulted cases.

Conventions:

  • attributes are named with symbols: :age, matching Map keys.
  • a struct's own functions are called on the instance (andrew.hello()), which passes it as self.

Functions

fn get(instance, attribute, default) The value of attribute, or default when the struct has no such attribute. instance.attribute is the direct form; this one pipes and takes a fallback.
fn put(instance, attribute, value) A new instance with attribute set to value. Raises when the struct does not declare attribute, since an instance's shape is its struct's.
fn update(instance, attribute, f) A new instance with attribute replaced by f applied to its current value — put when the new value depends on the old one.
fn keys(instance) The struct's attribute names, in declaration order.
fn values(instance) The struct's attribute values, in declaration order.
fn to_map(instance) The instance as a Map keyed by attribute name — the bridge to every Map function, since a struct has a fixed shape and a map does not.
fn is_a(instance, struct_module) Whether instance is an instance of struct_module. False for every non-struct value, so it is safe to ask of anything.

fn get(instance, attribute, default) ¶

The value of attribute, or default when the struct has no such attribute. instance.attribute is the direct form; this one pipes and takes a fallback.

Struct.get(Person{name: "Andrew"}, :name, "anonymous")   # == "Andrew"
Struct.get(Person{name: "Andrew"}, :nickname, nil)       # == nil
instance
the struct instance to read
attribute
the attribute name, as a symbol
default
the value to return when the attribute is not declared

Returns: the attribute's value, or default

fn put(instance, attribute, value) ¶

A new instance with attribute set to value. Raises when the struct does not declare attribute, since an instance's shape is its struct's.

Struct.put(Person{age: 40}, :age, 41)   # == Person{name: nil, age: 41}
instance
the struct instance to build on
attribute
the attribute to set, as a symbol
value
the value to store

Returns: a new instance of the same struct

fn update(instance, attribute, f) ¶

A new instance with attribute replaced by f applied to its current value — put when the new value depends on the old one.

Struct.update(Person{age: 40}, :age, do n -> n + 1)
# == Person{name: nil, age: 41}
instance
the struct instance to build on
attribute
the attribute to update, as a symbol
f
a lambda from the old value to the new one

Returns: a new instance of the same struct

fn keys(instance) ¶

The struct's attribute names, in declaration order.

Struct.keys(Person{name: "Andrew", age: 40})   # == [:name, :age]
instance
the struct instance to inspect

Returns: a List of symbols

fn values(instance) ¶

The struct's attribute values, in declaration order.

Struct.values(Person{name: "Andrew", age: 40})   # == ["Andrew", 40]
instance
the struct instance to inspect

Returns: a List of values

fn to_map(instance) ¶

The instance as a Map keyed by attribute name — the bridge to every Map function, since a struct has a fixed shape and a map does not.

Struct.to_map(Person{name: "Andrew", age: 40})
# == {name: "Andrew", age: 40}
instance
the struct instance to convert

Returns: a Map from attribute symbol to value

fn is_a(instance, struct_module) ¶

Whether instance is an instance of struct_module. False for every non-struct value, so it is safe to ask of anything.

Struct.is_a(Person{name: "Andrew"}, Person)   # == true
Struct.is_a(42, Person)                       # == false
instance
the value to test
struct_module
the struct to test against, as a module

Returns: true when instance was built from struct_module
