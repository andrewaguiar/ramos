NaiveDateTime

Summary

NaiveDateTime — a calendar date and a time of day, with no time zone. Date plus hour/minute/second/millisecond.

Module documentation

NaiveDateTime — a calendar date and a time of day, with no time zone. Date plus hour/minute/second/millisecond.

"Naive" is the standard term for this shape: a wall-clock reading with no attached zone or offset, so it cannot be converted to a precise instant on its own. Reach for DateTime when the offset from UTC matters — logging a timestamp, scheduling something relative to now, comparing readings taken in different places.

dt = NaiveDateTime.new(2024, 2, 9, 13, 45, 30)
dt.hour     # == 13
dt.minute   # == 45

As with Date, an out-of-range field normalizes rather than raising — second: 60 rolls into the next minute, hour: -1 into the previous day's last hour:

NaiveDateTime.new(2024, 2, 9, 23, 59, 60)   # == NaiveDateTime{year: 2024, month: 2, day: 10, hour: 0, minute: 0, second: 0, millisecond: 0}

Conventions:

  • compare follows Integer.compare: -1, 0, 1.
  • to_iso/parse round-trip through "YYYY-MM-DDTHH:MM:SS.mmm", always with milliseconds — the precision now reads the clock at.

function new(year, month, day, hour, minute, second) ¶

Builds a NaiveDateTime with millisecond: 0. Every field past year normalizes when it overflows or underflows its natural range, the same way Date.new's day does.

NaiveDateTime.new(2024, 2, 9, 13, 45, 30)
# == NaiveDateTime{year: 2024, month: 2, day: 9, hour: 13, minute: 45, second: 30, millisecond: 0}
NaiveDateTime.new(2024, 2, 9, 24, 0, 0)
# == NaiveDateTime{year: 2024, month: 2, day: 10, hour: 0, minute: 0, second: 0, millisecond: 0}
year
the calendar year, any integer
month
the month, 1..12
day
the day of month; out-of-range values roll over
hour
the hour, 0..23; out-of-range values roll over
minute
the minute, 0..59; out-of-range values roll over
second
the second, 0..59; out-of-range values roll over

Returns: a new NaiveDateTime

function now() ¶

The current date and time, read from the wall clock as UTC.

NaiveDateTime.now().year > 2000   # == true

Returns: the current NaiveDateTime

function from_epoch_millis(ms) ¶

The NaiveDateTime that is ms milliseconds after 1970-01-01T00:00:00.000 (millisecond 0). Negative values reach before the epoch.

NaiveDateTime.from_epoch_millis(0)
# == NaiveDateTime{year: 1970, month: 1, day: 1, hour: 0, minute: 0, second: 0, millisecond: 0}
NaiveDateTime.from_epoch_millis(-1)
# == NaiveDateTime{year: 1969, month: 12, day: 31, hour: 23, minute: 59, second: 59, millisecond: 999}
ms
milliseconds since the epoch, as an Integer

Returns: the corresponding NaiveDateTime

(private) from_epoch_millis's own body, so shift can reach it without calling the public function.

function parse(text) ¶

Parses "YYYY-MM-DDTHH:MM:SS" or "YYYY-MM-DD HH:MM:SS" — either a T or a plain space between the date and the time, as to_iso renders or as the N"..." sigil is written. The seconds' fractional part is optional and any number of digits (padded or truncated to milliseconds): "...:30", "...:30.5" and "...:30.123456" are all valid, meaning 0, 500 and 123 milliseconds respectively.

NaiveDateTime.parse("2024-02-09T13:45:30.500")
# == NaiveDateTime{year: 2024, month: 2, day: 9, hour: 13, minute: 45, second: 30, millisecond: 500}
NaiveDateTime.parse("2024-02-09 13:45:30.123456")
# == NaiveDateTime{year: 2024, month: 2, day: 9, hour: 13, minute: 45, second: 30, millisecond: 123}
text
a date-time in "YYYY-MM-DD[T ]HH:MM:SS[.fraction]" form

Returns: the corresponding NaiveDateTime

function compare(self, other) ¶

Orders two date-times as -1, 0 or 1 — the shape Integer.compare uses, since there is no built-in </> for structs.

NaiveDateTime.compare(NaiveDateTime{hour: 1}, NaiveDateTime{hour: 2})   # == -1
NaiveDateTime.compare(NaiveDateTime{hour: 2}, NaiveDateTime{hour: 1})   # == 1
NaiveDateTime.compare(NaiveDateTime{hour: 1}, NaiveDateTime{hour: 1})   # == 0
self
the first date-time
other
the second date-time

Returns: -1 when self is earlier, 1 when later, 0 when equal

function diff_millis(self, other) ¶

self

other
