Time

Summary

Time — a time of day: hour/minute/second/millisecond, with no date and no time zone.

Module documentation

Time — a time of day: hour/minute/second/millisecond, with no date and no time zone.

t = Time.new(13, 45, 30)
t.hour     # == 13
t.minute   # == 45

There is no day to carry into, so every field wraps at its own boundary instead of normalizing into the next one the way Date's day does — add_hours past 23 wraps back to 0:

Time.add_hours(Time{hour: 23}, 2)   # == Time{hour: 1, minute: 0, second: 0, millisecond: 0}

Conventions:

  • compare follows Integer.compare: -1, 0, 1.
  • to_iso/parse round-trip through "HH:MM:SS.mmm"; parse also accepts a bare "HH:MM:SS" (millisecond 0) and a fractional part of any precision ("HH:MM:SS.5" is 500ms, "HH:MM:SS.123456" truncates to 123ms) — this is also what the T"..." sigil parses.
  • see NaiveDateTime for this paired with a calendar date.

fn new(hour, minute, second) ¶

Builds a Time with millisecond: 0. Every field wraps at its own boundary rather than raising — hour: 24 is 0, hour: -1 is 23.

Time.new(13, 45, 30)   # == Time{hour: 13, minute: 45, second: 30, millisecond: 0}
Time.new(24, 0, 0)     # == Time{hour: 0, minute: 0, second: 0, millisecond: 0}
Time.new(-1, 0, 0)     # == Time{hour: 23, minute: 0, second: 0, millisecond: 0}
hour
the hour; wraps modulo 24
minute
the minute; wraps modulo 60
second
the second; wraps modulo 60

Returns: a new Time

fn now() ¶

The current time of day, read from the wall clock as UTC.

Time.now().hour < 24   # == true

Returns: the current Time

fn from_millis_of_day(ms) ¶

The Time that is ms milliseconds after midnight, wrapping at a day (86400000 ms) either direction.

Time.from_millis_of_day(0)        # == Time{hour: 0, minute: 0, second: 0, millisecond: 0}
Time.from_millis_of_day(-1)       # == Time{hour: 23, minute: 59, second: 59, millisecond: 999}
Time.from_millis_of_day(86400000) # == Time{hour: 0, minute: 0, second: 0, millisecond: 0}
ms
milliseconds since midnight, as an Integer; any value wraps

Returns: the corresponding Time

fn parse(text) ¶

Parses "HH:MM:SS" or "HH:MM:SS.fraction", fraction any number of digits (padded or truncated to milliseconds) — the shape to_iso renders, and what the T"..." sigil uses.

Time.parse("13:45:30")       # == Time{hour: 13, minute: 45, second: 30, millisecond: 0}
Time.parse("13:45:30.5")     # == Time{hour: 13, minute: 45, second: 30, millisecond: 500}
Time.parse("13:45:30.123456")
# == Time{hour: 13, minute: 45, second: 30, millisecond: 123}
text
a time of day in that form

Returns: the corresponding Time

fn compare(self, other) ¶

Orders two times as -1, 0 or 1 — the shape Integer.compare uses, since there is no built-in </> for structs.

Time.compare(Time{hour: 1}, Time{hour: 2})   # == -1
Time.compare(Time{hour: 2}, Time{hour: 1})   # == 1
Time.compare(Time{hour: 1}, Time{hour: 1})   # == 0
self
the first time
other
the second time

Returns: -1 when self is earlier, 1 when later, 0 when equal

fn diff_millis(self, other) ¶

The number of milliseconds from other to self — positive when self is later, negative when earlier. Both are read as times on the same day, so this does not wrap.

Time.diff_millis(Time{second: 10}, Time{second: 1})   # == 9000
self
the later (or earlier) time
other
the time to measure from

Returns: an Integer millisecond count
