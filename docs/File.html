File — reading, writing, and managing files on the host filesystem.

This is Ramos's window onto mutable state: files change over time. Every function here is therefore effectful and reports success or failure as a value you pattern match, never by raising:

  • fallible operations return (:ok, value) or (:error, reason)
  • operations with nothing to hand back return the bare :ok
  • exists and is_file return a plain true/false

reason is a lowercase symbol — :enoent (no such file), :eacces (permission denied), :eexist, :io_error, or :unsupported — so branches read cleanly:

case File.read("config.txt")
  (:ok, text) -> parse(text)
  (:error, :enoent) -> :use_defaults
  (:error, reason) -> (:error, (:config_unreadable, reason))

Every function takes a path; there are no open file handles. read and write move the whole file at once, which keeps the model simple and the values immutable.

Conventions:

  • paths are host-native strings; relative paths resolve against the cwd.
  • write truncates; append adds to the end; both create the file if it is missing.
  • mv is the one way to move a file: it tries a rename first and falls back to copy + delete, so it works across filesystems.

fn read(path) ¶

Reads the entire file at path into a string.

File.write("greeting.txt", "hello\n")
File.read("greeting.txt")   # == (:ok, "hello\n")
File.read("missing.txt")    # == (:error, :enoent)
path
the path to read

Returns: (:ok, contents), or (:error, reason) if it cannot be read

fn write(path, contents) ¶

Writes contents to path, replacing any existing content and creating the file if it does not exist.

File.write("out.txt", "hello\n")   # == :ok
path
the path to write
contents
the string to write

Returns: :ok, or (:error, reason) on failure

fn append(path, contents) ¶

Appends contents to the end of path, creating the file if it does not exist. Unlike write, existing content is preserved.

File.append("log.txt", "another line\n")   # == :ok
path
the path to append to
contents
the string to append

Returns: :ok, or (:error, reason) on failure

fn size(path) ¶

Returns the size of path in bytes.

File.write("greeting.txt", "hello\n")
File.size("greeting.txt")   # == (:ok, 6)
path
the path to measure

Returns: (:ok, bytes), or (:error, reason) if it cannot be read

fn rm(path) ¶

Deletes the file at path.

File.write("out.txt", "bye\n")
File.rm("out.txt")   # == :ok
path
the path to delete

Returns: :ok, or (:error, reason) (e.g. :enoent if it is not there)

fn cp(source, dest) ¶

Copies the file at source to dest, overwriting dest if it exists.

File.write("a.txt", "hello\n")
File.cp("a.txt", "b.txt")   # == :ok
source
the file to copy from
dest
the path to copy to

Returns: :ok, or (:error, reason) on failure

fn mv(source, dest) ¶

Moves the file at source to dest. Works across filesystems: it tries a rename first, then falls back to a copy followed by deleting source.

File.write("draft.txt", "hello\n")
File.mv("draft.txt", "final.txt")   # == :ok
source
the file to move from
dest
the path to move to

Returns: :ok, or (:error, reason) on failure

fn exists(path) ¶

Returns true if something exists at path (a file or a directory), else false. Use is_file to require that it is a regular file.

File.write("out.txt", "hello\n")
File.exists("out.txt")   # == true
File.exists("missing")   # == false
path
the path to test

Returns: true if path exists, else false

fn is_file(path) ¶

Returns true if path exists and is a regular file, else false (including when path is a directory or does not exist).

File.write("out.txt", "hello\n")
Dir.mkdir("src")
File.is_file("out.txt")   # == true
File.is_file("src")       # == false
path
the path to test

Returns: true if path is a regular file, else false

fn touch(path) ¶

Creates path if it does not exist, and updates its modified time to now. Existing content is preserved — the file-manager equivalent of touch(1).

File.touch("build.stamp")   # == :ok
path
the path to touch

Returns: :ok, or (:error, reason) on failure

fn chmod(path, mode) ¶

Sets the permission bits of path. mode is the numeric permission — for example 493 is rwxr-xr-x and 420 is rw-r--r--.

File.write("run.sh", "echo hi\n")
File.chmod("run.sh", 493)   # == :ok
path
the path to change
mode
the numeric permission bits

Returns: :ok, (:error, reason), or (:error, :unsupported) off Unix
