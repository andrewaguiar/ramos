Module documentation

String — operations on immutable, UTF-8 text.

Strings in Ramos are double-quoted ("hi"), interpolated with #{name}, and concatenated with <>. Like every value in Ramos they are immutable: every function here returns a new string rather than mutating its input.

Unlike lists, strings have no head | tail destructuring in the language, so the character-level primitives (indexing, slicing, casing, splitting, reversing) delegate to the host via native. Concatenation is the <> operator rather than a function here, and the rest compose through pipes just like the List module:

"  Hello World  "
| String.trim()
| String.downcase()
| String.replace(" ", "_")     # == "hello_world"

Joining a list of strings back into one is List.join (not here), the natural inverse of split. Numeric parsing lives on Kernel (to_integer / to_float), and so does emptiness: is_empty(s) already covers strings, so this module does not repeat it.

Conventions:

  • indexes are zero-based and count Unicode code points.
  • at returns a single-character string; Ramos has no separate char type.
  • search functions that may miss return nil.

the string to measure

fn at(s, index) ¶

Returns the single-character string at zero-based index, or nil if out of range. Ramos has no separate char type, so the result is a String.

String.at("hello", 9)   # == nil
s
the string to read from
index
the zero-based code-point position to read

Returns: the single-character String at index, or nil if out of range

fn split(s, sep) ¶

Splits s at each occurrence of sep, returning a list of parts. Empty sep splits into one-character strings. To rejoin, use List.join.

String.split("a,b,c", ",")   # == ["a", "b", "c"]
s

Returns: a List of the String parts

fn pad_left(s, width, pad_char) ¶

Returns s left-padded with pad_char until it reaches at least width characters. Already-long-enough s comes back unchanged. pad_char is a single character; a longer one may overshoot width.

String.pad_left("7", 3, "0")     # == "007"
String.pad_left("hello", 3, "0") # == "hello"
s
the string to pad
width

pad_char

Returns: s, left-padded to at least width characters
