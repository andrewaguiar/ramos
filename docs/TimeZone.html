Module documentation

TimeZone — a name paired with a fixed offset from UTC.

There is no IANA time zone database here (no dependency ships one), so a TimeZone cannot answer "what was the offset in Berlin on this date" — daylight saving and historical rule changes are out of scope. What it does give a raw offset_minutes integer (as DateTime takes) is a name to carry alongside it, and the shared "Z"/±HH:MM text form:

ist = TimeZone.fixed("IST", 330)
ist.name             # == "IST"
ist.offset_minutes   # == 330
DateTime.now_in(ist).offset_minutes   # == 330

utc, fixed, and from_offset_minutes build one; DateTime.now_in and DateTime.in_time_zone are the bridge to DateTime. A DateTime only ever keeps the numeric offset_minutes, not the name it arrived with, so reading it back with DateTime.time_zone gives a zone named after its offset ("+05:30"), not "IST" — a name is a label you attach going in, not one a DateTime remembers on its own.

Conventions:

  • offset_minutes is checked against the real range any UTC offset can fall in, -12:00..+14:00 (-720..840), but the name is never checked — TimeZone.fixed("literally anything", 0) is fine. A TimeZone only ever carries what its caller gives it.
  • compare orders by offset_minutes, west to east.

fn utc() ¶

The UTC zone: offset_minutes: 0.

TimeZone.utc()   # == TimeZone{name: "UTC", offset_minutes: 0}

Returns: TimeZone{name: "UTC", offset_minutes: 0}

fn fixed(name, offset_minutes) ¶

A zone called name, at a fixed offset_minutes from UTC.

TimeZone.fixed("IST", 330)   # == TimeZone{name: "IST", offset_minutes: 330}
name
the zone's label — anything, not checked against offset_minutes
offset_minutes
the offset from UTC, in minutes; must be -720..840

Returns: a new TimeZone

fn from_offset_minutes(offset_minutes) ¶

A zone named after its own offset — "UTC" at 0, otherwise the ±HH:MM text offset_text renders. For when a zone has no friendlier name to give it.

TimeZone.from_offset_minutes(0)      # == TimeZone{name: "UTC", offset_minutes: 0}
TimeZone.from_offset_minutes(-300)   # == TimeZone{name: "-05:00", offset_minutes: -300}
offset_minutes
the offset from UTC, in minutes; must be -720..840

Returns: a new TimeZone, named by its offset

fn parse(text) ¶

A zone parsed from offset_text's shape: "Z" for UTC, or a signed "±HH:MM". The zone is named after the offset — this is the inverse of from_offset_minutes, not of fixed (a parsed zone has no way to recover a friendlier name).

TimeZone.parse("Z")        # == TimeZone{name: "UTC", offset_minutes: 0}
TimeZone.parse("-05:00")   # == TimeZone{name: "-05:00", offset_minutes: -300}
text
"Z" or a signed "±HH:MM" offset

Returns: the corresponding TimeZone

fn offset_text(offset_minutes) ¶

offset_minutes rendered as "Z" (when zero) or a signed "±HH:MM" — the suffix DateTime.to_iso appends.

TimeZone.offset_text(0)      # == "Z"
TimeZone.offset_text(330)    # == "+05:30"
TimeZone.offset_text(-300)   # == "-05:00"
offset_minutes
the offset from UTC, in minutes

Returns: "Z" or a signed "±HH:MM" string

fn parse_offset_text(text) ¶

The inverse of offset_text: "Z" or a signed "±HH:MM" parsed back to a minute count.

TimeZone.parse_offset_text("Z")        # == 0
TimeZone.parse_offset_text("+05:30")   # == 330
TimeZone.parse_offset_text("-05:00")   # == -300
text
"Z" or a signed "±HH:MM" offset

Returns: the offset from UTC, in minutes

fn compare(self, other) ¶

Orders two zones by offset_minutes, west to east, as -1, 0 or 1 — the shape Integer.compare uses. Two zones at the same offset compare equal regardless of name.

TimeZone.compare(TimeZone.fixed("A", -300), TimeZone.fixed("B", 0))   # == -1
TimeZone.compare(TimeZone.utc(), TimeZone.fixed("Also UTC", 0))       # == 0
self
the first zone
other
the second zone

Returns: -1 when self is west of other, 1 when east, 0 when level

fnp pad(n, width) private ¶

(private) n rendered as decimal digits, left-padded with zeros to at least width characters. Backs offset_text.
