Actor ¶

a module implements Actor by defining call, which returns (reply, new_state). cast has no reply: it returns only the new state, and runs later — before the next call, or at program end.

module Cache
  implements Actor

  function call(f, args, state, config)
    case f
      :get ->
        [key] = args
        (Map.get(state, key, nil), state)
      :set ->
        [key, value] = args
        (:ok, Map.put(state, key, value))

  function cast(f, args, state, config)
    [key] = args
    Map.delete(state, key)

client half — callers never write call_actor / cast_actor

  function start()
    start_actor(:cache, Cache, {}, {})

  function get(key)
    call_actor(:cache, Cache, :get, [key])

  function set(key, value)
    call_actor(:cache, Cache, :set, [key, value])
  function clear(key)
    cast_actor(:cache, Cache, :clear, [key])

Alias ¶

alias gives a module a shorter name, cutting the verbosity of long namespaces. It works for pure modules and struct modules alike.

alias Geometry as Geo
alias Geometry.Circle as Circle
alias Geometry.Rectangle as Rect

area = Geo.circle_area(5)   # == 78.5
circle = Circle.area(5)
rectangle = Rect.area(10, 20)

Without as, the local name is the path's last segment — what most aliases want. as is for breaking a collision between two of them.

alias Drawing.Shapes.Ellipse

ellipse = Ellipse.area(10, 20)

A module aliases the modules it uses at the top of its own body.

module Report
  alias Geometry.Circle
  alias Drawing.Shapes.Ellipse as Oval

  function areas(r)
    (Circle.area(r), Oval.area(r, r))

Arithmetic ¶

arithmetic operators. Whitespace around a binary operator is required: 1 + 2, never 1+2.

sum = 1 + 2
difference = 10 - 4
product = 3 * 4
quotient = 10 / 3          # int / int truncates toward zero  # == 3
remainder = -7 % 3         # follows the sign of the divisor  # == 2
power = 2 ** 10            # == 1024
negated = -5               # unary minus may hug its operand

Mixing an int and a float widens the int to a float.

widened = 1 + 1.5          # == 2.5
float_division = 10 / 4.0  # == 2.5

Precedence: ** binds tighter than unary minus, * tighter than +.

precedence = -2 ** 2 + 3 * 4   # == (-(2 ** 2)) + 12 == 8

Case ¶

case matches a value against patterns top to bottom and runs the first match. _ is the wildcard. Where if branches on a condition and cond on a chain of them, case branches on the shape of a value.

x = 2

A block whose value is assigned starts on the line after =.

matched =
  case x
    1 -> :one
    2 -> :two
    _ -> :other

An arm body can be a block: keep the -> at the end of the arm and indent the body; its last expression is the arm's value.

described =
  case [1, 2, 3]
    [] -> "empty"
    [only] -> "single: #{only}"
    [head | tail] ->
      rest = size(tail)
      "head #{head} and #{rest} more"

Comments ¶

a comment runs from # to the end of the line.

A comment can stand on its own line, above the code it describes.

x = 1  # ...or trail a statement.

Blank comment lines are ignored, and so are the blank lines around them:

A # inside a string is just a character, not a comment.

marker = "# not a comment"
print(marker)

Comparison ¶

comparison operators, each returning a bool.

equal = 1 == 1
not_equal = 1 != 2
less = 1 < 2
greater = 1 > 2
less_or_equal = 1 <= 2
greater_or_equal = 1 >= 2

Comparison binds looser than arithmetic, so the sum happens first.

in_range = 1 + 2 * 3 == 7

Cond ¶

cond takes the first arm whose condition is truthy. It is case over a sequence of guards, for when no single value is matched.

x = 5

A block whose value is assigned starts on the line after =.

sign =
  cond
    x > 0 -> :positive
    x < 0 -> :negative
    true -> :zero

true -> is the idiomatic catch-all arm. Arms take blocks too.

label =
  cond
    x > 100 ->
      big = x * 2
      "big: #{big}"
    true -> "small"

Destructuring ¶

patterns work in plain assignment, not just in case.

Lists destructure with the cons operator |.

[head | tail] = [1, 2, 3]              # head == 1, tail == [2, 3]
[first, second | rest] = [1, 2, 3, 4]  # first == 1, second == 2, rest == [3, 4]

Tuples are the idiomatic way to unpack a small fixed record.

person = ("Andrew", 40)
(name, age) = person                   # name == "Andrew", age == 40

Any combination nests, and _ discards.

((a, _), [b | _]) = ((1, 2), [3, 4, 5])   # a == 1, b == 3

Maps and struct instances destructure by field.

{name: bound_name} = {name: "andrew", age: 40}
Person{age: bound_age} = Person{name: "Andrew", age: 40}

Doc comments ¶

documentation lives inline, as a comment block placed immediately below the definition it describes. @module_doc documents a module, @doc a function; each marker is followed by an empty # line.

module Greeter

@module_doc

Greeter — builds greetings.

Greeter.greet("Andrew")   # == "Ola Andrew"
  function greet(name)

@doc

Returns the greeting for name.

Greeter.greet("Andrew")   # == "Ola Andrew"
    "Ola #{name}"

Error tuples ¶

Ramos has no exceptions. A function that can fail returns a tagged tuple instead: (:ok, value) on success, (:error, (:type, msg)) on failure. The error is an ordinary value, so it is matched like any other.

function withdraw(balance, amount)
  cond
    amount <= 0 -> (:error, (:invalid_amount, "amount must be positive"))
    amount > balance -> (:error, (:insufficient_funds, "balance is too low"))
    true -> (:ok, balance - amount)

case reads the tag, and the error's own shape destructures in the pattern, so each failure is handled where it is named.

result =
  case withdraw(100, 250)
    (:ok, remaining) -> "left: #{remaining}"
    (:error, (:invalid_amount, message)) -> "bad request: #{message}"
    (:error, (:insufficient_funds, message)) -> "declined: #{message}"
    (:error, (_, message)) -> "failed: #{message}"

print(result)

run chains steps that each return (:ok, _), stopping at the first one that does not match — the flat alternative to nesting a case per step.

total =
  run
    (:ok, after_rent) = withdraw(1000, 400)
    (:ok, after_food) = withdraw(after_rent, 200)
    after_food

print(total)

Guards ¶

a when guard sits between a pattern and its ->, narrowing a match beyond the pattern's shape.

function classify(list)
  case list
    [head | _] when head > 100 -> :big
    [head | _] when head > 0 -> :small
    [_ | _] -> :non_positive
    [] -> :empty

Guards are plain expressions, so they combine with and / or / not.

function admits(user)
  case user
    ({name: n, age: a}, :admin) when a > 18 and not (n == "") -> "Admin #{n}"
    ({name: n}, :guest) -> "Guest #{n}"
    _ -> "Unknown"

If ¶

if is the two-branch conditional: a condition, an indented body, and an optional else. Any value works as the condition, since only false and nil are falsy. There is no else if — a chain of conditions is cond.

x = 5

if x > 3
  print("big")
else
  print("small")

else is optional; without one, the branch not taken yields nil.

if x > 100
  print("never")

if is an expression, so it can be assigned — the block starts on its own line, like any other block on the right of =.

grade =
  if x > 3
    :high
  else
    :low

Any truthy value: is_truthy is the same rule written down.

if "text"
  print(is_truthy(x))

One guarded statement fits on one line: <statement> when <condition> — the same conditional, so no else half and no assignment on the left.

print("big") when x > 3

Implements ¶

a struct declares the traits it implements with implements, at the top of the struct body. It must define every function the trait requires; the trait's defaults come for free.

struct Person
  implements Helloable
  implements Describable

  attributes
    name: nil
    age: 0

  function is_over_eighteen(self)   # required by Helloable
    self.age > 18

Lambdas ¶

anonymous functions. Lambdas are values, so they can be bound, passed and piped.

Single-expression: use -> and stay on one line.

add = do x, y -> x + y
three = add(1, 2)

Multi-statement: drop the ->, indent the body, last expression returns. The body is a block, so — like a case — it starts on the line after the =.

double_then_add =
  do x, y
    z = x + y
    z * 2

ten = double_then_add(2, 3)

No parameters, and passed straight into a function call.

answer = do -> 42
doubled = List.map([1, 2, 3], do x -> x * 2)

List concat ¶

++ concatenates two lists, returning a new one.

joined = [1, 2] ++ [3, 4]   # == [1, 2, 3, 4]
prepended = [0] ++ joined   # == [0, 1, 2, 3, 4]
with_empty = [] ++ [1]      # == [1]

[head | tail] is the cons form — a literal/pattern shape, not an operator.

[head | tail] = joined

Literals ¶

one of every literal Ramos has.

int = 42
float = 3.14
string = "andrew"
symbol = :symbol
yes = true
no = false
nothing = nil
list = [1, 2, 3]
tuple = (1, 2, 3)
map = {name: "andrew"}

Only false and nil are falsy...

falsy = [false, nil]

...everything else is truthy, including 0, "" and [].

truthy = [0, "", []]

Logical ¶

the word-form logical operators. Ramos has no &&, || or !.

both = true and false   # `and` short-circuits: a false left side skips the right
either = true or false  # `or` short-circuits too
negated = not true

Precedence, loosest to tightest: or < and < not < comparison.

mixed = 1 < 2 and not (3 > 4) or false

Map merge ¶

++ merges two maps, returning a new one.

merged = {a: 1} ++ {b: 2}      # == {a: 1, b: 2}
overridden = {a: 1} ++ {a: 2}  # right side wins on duplicate keys  # == {a: 2}
defaults = {} ++ merged

Maps are insertion-ordered and immutable — ++ returns a new map.

nested = {user: {name: "andrew", age: 40}, active: true}

Module ¶

a pure module is a namespace of functions with no per-instance state. It is itself a value, so it can be passed around and inspected.

module PersonUtils
  function hello(person)
    print("Ola #{person.name}, eu tenho #{person.age}")

  function hi_all(people)
    people
    | List.map(do p -> "hi #{p.name}")
    | List.join(", ")

Multiline strings ¶

""" opens a multiline string. The opening quotes are followed straight by a newline, content sits one level (2 spaces) past the opening line, and the closing quotes stand alone at the opening line's indentation. Every content line keeps its trailing newline.

Like case or run, a multiline string being assigned starts on the line after the =, so the assignment does not hang open across the content.

str =
  """
    Hi there

    This is a multiline string
  """

print(str)

Here the string opens at the function-body level, so "Usage: ..." is flush left in the value while " -h ..." keeps its two extra spaces. Interpolation works exactly as in single-line strings.

function usage(name)
  """
    Usage: #{name} <file>
      -h  show this help
  """

Namespaced module ¶

module names are CamelCase and may be namespaced with .. The namespace maps to the file path: MyApp.Business.SystemUser lives at src/my_app/business/system_user.rmo.

module MyApp.Business.SystemUser
  function create(name)
    (:ok, name)

  function describe()
    "a namespaced module"

Pipe ¶

| passes the value on its left as the first argument to the module function on its right, so data flows top to bottom. It always starts its own line, at the same indentation as what comes before it.

shouted = ["ana", "bob"]
| List.map(do n -> String.upcase(n))

Pipes chain, each on its own line.

sentence = ["ana", "bob"]
| List.map(do n -> String.upcase(n))
| List.join(", ")

a then | M.f(b) means exactly M.f(a, b) — these two are the same call.

piped = [1, 2, 3, 4]
| List.filter(do x -> Integer.is_even(x))
plain = List.filter([1, 2, 3, 4], do x -> Integer.is_even(x))

Private functions ¶

helper defines a private function, callable only from inside its own module. function is public.

module Accounts
  function create(name)
    (:ok, normalize(name))   # a public function may call a private one

  helper normalize(name)
    String.downcase(name)

Run ¶

run is a block of matches. Statements run in order; the first pattern = value that does not match ends the block and is its result, so a chain of validations reads flat instead of as nested cases.

Bindings flow to later statements; the result is the last one's value, or the value that failed to match, e.g. (:error, (:invalid_price, "...")). The block starts on the line after =, as every assigned block must.

total =
  run
    (:ok, price) = fetch_price(item)
    (:ok, qty) = fetch_quantity(item)
    price * qty

A run may close with a case written without a subject: the block's result is the subject, so success and failure are handled side by side.

run
  :ok = validate_id(data)
  :ok = validate_name(data)
  :ok = validate_age(data)
case
  :ok ->
    print("valid")

  err ->
    print("rejected: #{err}")

Sigils ¶

a letter hugging a string desugars to a .parse call.

date = D"2024-02-29"                    # == Date.parse("2024-02-29")
time = T"13:45:30"                      # == Time.parse("13:45:30")
naive = N"2024-02-09T13:45:30.500"      # == NaiveDateTime.parse(...)
zoned = U"2024-02-09T13:45:30.500Z"     # == DateTime.parse(...)

String concat ¶

<> concatenates two strings.

joined = "a" <> "b"                  # == "ab"
greeting = "Ola" <> " " <> "Andrew"  # left-associative

<> binds looser than arithmetic, so 1 + 2 is evaluated first.

counted = "total: " <> to_string(1 + 2)

String interpolation ¶

#{...} embeds an expression inside a string.

name = "andrew"
greeting = "Ola #{name}, you have #{1 + 1} new messages"

Any expression works, including calls...

report = "size: #{size([1, 2, 3])}"

...and a string holding an interpolation of its own.

nested = "outer #{"inner #{name}"}"

Escapes: \n \t \" \\ and \#{, which suppresses interpolation.

escaped = "line\n\ttab \"quoted\" backslash \\ literal \#{name}"

Struct ¶

a struct declares a typed record. attributes names each field with its default, and instances are immutable: every update returns a new one.

struct Person
  attributes
    name: nil
    age: 0

  function hello(self)
    print("Ola #{self.name}, eu tenho #{self.age}")

Construction is the map-literal syntax prefixed by the struct name; omitted fields take their declared defaults, and field access is dot syntax.

andrew = Person{name: "Andrew", age: 40}
andrew.hello()

with_defaults = Person{}   # == Person{name: nil, age: 0}
oldest =
  andrew
  | Struct.put(:age, 41)
  | Struct.update(:age, do a -> a + 1)

andrew.age = 41 rebinds andrew to a new instance, sugar for that same call.

andrew.age = 41

fields = Struct.keys(andrew)             # == [:name, :age]
as_map = Struct.to_map(oldest)           # == {name: "Andrew", age: 42}
is_person = Struct.is_a(andrew, Person)  # == true

Struct errors ¶

a struct makes a good error payload once a symbol and a message aren't enough detail: it destructures in case like any other pattern, field by field, including matching on a literal field value.

struct DeclineReason
  attributes
    code: 0
    message: nil

function charge(amount)
  cond
    amount <= 0 -> (:error, DeclineReason{code: 555, message: "must be positive"})
    amount > 10000 -> (:error, DeclineReason{code: 556, message: "too large"})
    true -> (:ok, amount)

result =
  case charge(50000)
    (:ok, charged) -> "charged #{charged}"
    (:error, DeclineReason{code: 556, message: message}) -> "too large: #{message}"
    (:error, DeclineReason{message: message}) -> "declined: #{message}"

print(result)

Trait ¶

a trait declares a contract of functions. A function with a body is a default implementation; a function without one is required, and every implementer must define it.

trait Helloable
  function hello(self)
    print("Ola #{self.name}, eu tenho #{self.age}")

  function describe(self)
    "#{self.name} (#{self.age})"

  function is_over_eighteen(self)   # required, no body

Variables ¶

assignment binds a name to a value.

x = 100
name = "andrew"
pi = 3.14

Rebinding, not mutation: x now names a new value, and 100 was never changed.

x = x + 1

Names are snake_case, a-z_ only — no ? or !.

main_user_name = name
