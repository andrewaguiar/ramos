Module documentation

List — operations on persistent, immutable lists.

Lists in Ramos are singly-linked and pattern matched against the empty list [] and the cons cell [head | tail]. Every function here returns a new list rather than mutating its input — values in Ramos are immutable.

The module is built around a few small combinators — map, filter, reduce — from which most of the rest are derived. This keeps the implementation tiny and makes the functions compose cleanly through pipes:

[1, 2, 3, 4]
| List.filter(do x -> Integer.is_even(x))
| List.map(do x -> x * 10)            # == [20, 40]

Conventions:

  • predicates use Ramos truthiness — only false and nil are falsy.
  • search functions that may miss return nil.
  • index arguments are zero-based.
  • a _by suffix (sort_by, max_by, min_by, dedup_by) means the plain version's comparison is replaced by a key f returns, not the elements themselves.
  • a function whose own recursive call is not the last thing it does ([f(head)] ++ recurse(tail), say) is written instead as a private _loop helper carrying a reverse-order accumulator, so the recursion is tail-recursive and runs in constant native-stack space; the public function then reverses the result once. each, reduce, find, drop, and the other functions whose own recursive call already is the last thing they do need no such helper.

function group_by(list, f) ¶

Groups the elements of list by the key returned by f, returning a map from key to the list of elements sharing that key, in original order.

f must return a valid map key — an Integer, String or Symbol. A predicate returning a boolean is the common slip; yield a symbol instead:

List.group_by([:ok, :error, :ok], do x -> x)
# == {ok: [:ok, :ok], error: [:error]}
parity = do x -> cond
  Integer.is_even(x) -> :even
  true -> :odd

# == {odd: [1, 3], even: [2, 4]}
list
the list to group
f
a lambda returning the grouping key for an element

Returns: a Map from key to the list of elements with that key, in order
