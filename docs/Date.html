Date

Summary

Date — a calendar date: year, month, and day, with no time-of-day or time zone. Built on the proleptic Gregorian calendar.

Module documentation

Date — a calendar date: year, month, and day, with no time-of-day or time zone. Built on the proleptic Gregorian calendar.

Construct with new, today, from_epoch_day, or parse; read a field with dot access, like any struct:

d = Date.new(2024, 2, 29)
d.year    # == 2024
d.month   # == 2

An out-of-range day normalizes rather than raising — day: 0 is the last day of the previous month, one past the last day rolls into the next — so "the last day of this month" is just Date.new(year, month + 1, 0). month itself must be 1..12.

Date.new(2024, 3, 0)    # == Date{year: 2024, month: 2, day: 29}
Date.new(2024, 1, 32)   # == Date{year: 2024, month: 2, day: 1}

Two dates compare structurally with ==, like any other struct — but there is no built-in </>, since arbitrary structs are not ordered. Use compare instead, or sort by to_epoch_day:

Date.new(2024, 1, 1) == Date.new(2024, 1, 1)               # == true
Date.compare(Date.new(2024, 1, 1), Date.new(2024, 1, 2))   # == -1

Conventions:

  • every date is proleptic Gregorian, with no time zone — today reads the wall clock as UTC.
  • compare follows Integer.compare/Float.compare: -1, 0, 1.
  • the attributes default to the epoch, 1970-01-01, so Date{} is a real (if arbitrary) date rather than a half-built value.

function new(year, month, day) ¶

Builds a Date. day normalizes when it falls outside the month — 0 is the last day of the previous month, one past the last day rolls into the next.

Date.new(2024, 2, 29)   # == Date{year: 2024, month: 2, day: 29}
Date.new(2024, 3, 0)    # == Date{year: 2024, month: 2, day: 29}
Date.new(2023, 2, 29)   # == Date{year: 2023, month: 3, day: 1}
year
the calendar year, any integer
month
the month, 1..12
day
the day of month; out-of-range values roll over

Returns: a new Date

function today() ¶

Today's date, read from the wall clock as UTC.

Date.today().year > 2000   # == true

Returns: the current Date

function from_epoch_day(epoch_day) ¶

The Date that is epoch_day days after 1970-01-01 (day 0). Negative values reach before the epoch.

Date.from_epoch_day(0)    # == Date{year: 1970, month: 1, day: 1}
Date.from_epoch_day(-1)   # == Date{year: 1969, month: 12, day: 31}
epoch_day
days since 1970-01-01, as an Integer

Returns: the corresponding Date

function parse(text) ¶

Parses an ISO-8601 calendar date, "YYYY-MM-DD".

Date.parse("2024-02-29")   # == Date{year: 2024, month: 2, day: 29}
text
a date in "YYYY-MM-DD" form

Returns: the corresponding Date

function to_epoch_day(self) ¶

self as the number of days since 1970-01-01 — the bridge to arithmetic and comparison.

Date.to_epoch_day(Date{year: 1970, month: 1, day: 1})     # == 0
Date.to_epoch_day(Date{year: 1969, month: 12, day: 31})   # == -1
self
the date to convert

Returns: an Integer day count, negative before the epoch

function to_iso(self) ¶

self rendered as "YYYY-MM-DD" (ISO-8601), zero-padded.

Date.to_iso(Date{year: 2024, month: 2, day: 9})   # == "2024-02-09"
self
the date to render

Returns: the ISO-8601 string

function add_days(self, n) ¶

self shifted by n days — negative moves backward.

Date.add_days(Date{year: 2024, month: 2, day: 28}, 1)    # == Date{year: 2024, month: 2, day: 29}
Date.add_days(Date{year: 2024, month: 1, day: 1}, -1)    # == Date{year: 2023, month: 12, day: 31}
self
the starting date
n
how many days to add (negative subtracts)

Returns: a new Date

function add_years(self, n) ¶

self shifted by n years, keeping the month and day — except a leap day (month: 2, day: 29) landing on a non-leap year, which rolls to March 1, the same normalization new does for any other overflowing day.

Date.add_years(Date{year: 2024, month: 2, day: 29}, 1)    # == Date{year: 2025, month: 3, day: 1}
Date.add_years(Date{year: 2020, month: 6, day: 15}, -5)   # == Date{year: 2015, month: 6, day: 15}
self
the starting date
n
how many years to add (negative subtracts)

Returns: a new Date

function add_weeks(self, n) ¶

self shifted by n weeks (n * 7 days) — negative moves backward.

Date.add_weeks(Date{year: 2024, month: 1, day: 1}, 1)    # == Date{year: 2024, month: 1, day: 8}
Date.add_weeks(Date{year: 2024, month: 1, day: 8}, -1)   # == Date{year: 2024, month: 1, day: 1}
self
the starting date
n
how many weeks to add (negative subtracts)

Returns: a new Date

function add_months(self, n) ¶

self shifted by n months, carrying into the year and normalizing an overflowing day the same way new does — "same day next month" for day: 31 run against a 30-day month rolls into the one after.

Date.add_months(Date{year: 2024, month: 1, day: 15}, 1)    # == Date{year: 2024, month: 2, day: 15}
Date.add_months(Date{year: 2024, month: 11, day: 15}, 3)   # == Date{year: 2025, month: 2, day: 15}
Date.add_months(Date{year: 2024, month: 1, day: 15}, -1)   # == Date{year: 2023, month: 12, day: 15}
self
the starting date
n
how many months to add (negative subtracts)

Returns: a new Date

function compare(self, other) ¶

Orders two dates as -1, 0 or 1 — the shape Integer.compare and Float.compare use, since there is no built-in </> for structs.

Date.compare(Date{year: 2024, month: 1, day: 1}, Date{year: 2024, month: 1, day: 2})   # == -1
Date.compare(Date{year: 2024, month: 1, day: 2}, Date{year: 2024, month: 1, day: 1})   # == 1
Date.compare(Date{year: 2024, month: 1, day: 1}, Date{year: 2024, month: 1, day: 1})   # == 0
self
the first date
other
the second date

Returns: -1 when self is earlier, 1 when later, 0 when equal

function diff_days(self, other) ¶

The number of days from other to self — positive when self is later, negative when earlier.

Date.diff_days(Date{year: 2024, month: 1, day: 10}, Date{year: 2024, month: 1, day: 1})   # == 9
Date.diff_days(Date{year: 2024, month: 1, day: 1}, Date{year: 2024, month: 1, day: 10})   # == -9
self
the later (or earlier) date
other
the date to measure from

Returns: an Integer day count

function day_of_week(self) ¶

The day of the week self falls on.

`:thursday`, `:friday`, `:saturday`
Date.day_of_week(Date{year: 1970, month: 1, day: 1})   # == :thursday
Date.day_of_week(Date{year: 2024, month: 1, day: 1})   # == :monday
self
the date to inspect

Returns: one of :sunday, :monday, :tuesday, :wednesday,

function is_leap_year(year) ¶

Whether year has a February 29th, by the proleptic Gregorian rule: divisible by 4, except centuries, unless also divisible by 400.

Date.is_leap_year(2024)   # == true
Date.is_leap_year(1900)   # == false
Date.is_leap_year(2000)   # == true
year
the calendar year to test

Returns: true when year is a leap year

function days_in_month(self) ¶

How many days are in self's month.

Date.days_in_month(Date{year: 2024, month: 2, day: 1})   # == 29
Date.days_in_month(Date{year: 2023, month: 2, day: 1})   # == 28
self
the date whose month to measure

Returns: 28-31
