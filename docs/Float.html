Module documentation

Float — operations on floating-point numbers.

3.14 is a Float. Arithmetic lives in the operators (+, -, *, /, **); this module holds the rounding, the constants, and the tests that read better as named functions.

Float.round(2.6)   # == 3
Float.pi()         # == 3.141592653589793

An Integer and a Float never compare equal — 1 == 1.0 is false — so convert explicitly when you mean to compare across the two.

Rounding is built on Kernel's to_integer (which truncates toward zero), and the special values fall out of the arithmetic itself — no native needed for either. exp/log/log_two/log_ten/sin/cos/tan are the exception: transcendental functions have no operator to build on, so those seven are the only natives behind this module. (No digit may appear in a Ramos identifier, which is why the base-2 and base-10 logs are spelled out rather than log2/log10.)

Kernel already converts and truncates, so this module does not repeat it: use to_integer(x) to drop the fraction, to_float(text) to parse, and to_string(x) to render.

Conventions:

  • floor, ceil and round all return an Integer.
  • round goes half away from zero: 2.5 rounds to 3, -2.5 to -3.

fn sign(x) ¶

-1.0, 0.0 or 1.0 according to the sign of x. Neither infinity nor nan gets special treatment: sign on an infinity follows its direction, same as any other float, and nan < 0.0/nan > 0.0 are both false so sign(Float.nan()) is 0.0 — the same convention compare already uses for nan.

x
the float to test
