Integer — operations on whole numbers.

42 is an Integer. Arithmetic lives in the operators (+, -, *, /, %, **) rather than here; this module holds what reads better as a named function, especially the predicates passed to List:

[1, 2, 3, 4]
| List.filter(do x -> Integer.is_even(x))   # == [2, 4]

Kernel already converts, so this module does not repeat it: use to_integer(text) to parse, to_float(n) to widen, to_string(n) to render.

Conventions:

  • integer division truncates toward zero, and % follows the sign of the divisor — both are operator behaviour, documented in the README.

function times(n, f) ¶

Applies f to each of 0, 1, ..., n - 1, collecting the results. Empty when n is zero or negative — checked directly, since List.range(0, n - 1) alone would count down from 0 once n - 1 goes negative, rather than stopping at an empty list.

Integer.times(3, do i -> i * 2)   # == [0, 2, 4]
Integer.times(0, do i -> i)       # == []
n
how many times to apply f
f
a lambda taking the zero-based index

Returns: a List of the n results, in order
